# Path Learn

> Um laboratório pessoal para consolidar fundamentos, experimentar tecnologias e documentar minha evolução como desenvolvedor.

## Sobre este projeto

O `path-learn` nasceu de uma decisão de recomeçar meus estudos de desenvolvimento de software de uma forma mais estruturada.

Como desenvolvedor autodidata, aprendi grande parte do que sei através de projetos, documentação, cursos e experimentação. Esse processo me permitiu construir diversas aplicações, mas também revelou algumas lacunas nos meus fundamentos.

Em vez de continuar apenas avançando para novos frameworks e tecnologias, decidi voltar aos fundamentos e reconstruir minha base.

Aqui reúno exercícios, pequenos projetos e experimentos relacionados principalmente a:

* JavaScript
* React
* Next.js
* TypeScript
* C#
* ASP.NET Core
* Blazor
* CSS
* SQL
* Git
* Arquitetura de software
* Boas práticas e padrões de desenvolvimento

## O objetivo

O objetivo deste repositório não é simplesmente acumular projetos.

Quero utilizar cada projeto como uma oportunidade para praticar conceitos, entender melhor as ferramentas que utilizo e desenvolver novamente a capacidade de transformar uma ideia em código sem depender de tutoriais passo a passo.

Alguns projetos são deliberadamente simples, pois representam exercícios de fundamentos. Outros serão gradualmente mais complexos, incorporando conceitos de arquitetura, persistência de dados, autenticação, testes, integração entre frontend e backend e outras práticas utilizadas no desenvolvimento profissional.

## Aprendizado através da prática

Durante essa jornada, pretendo seguir uma progressão:

**Aprender → praticar → construir → refatorar → documentar**

Nem todo projeto aqui representa uma aplicação pronta para produção. Alguns existem simplesmente para experimentar um conceito específico.

Isso também faz parte do processo.

## Em evolução

Este repositório está em constante evolução.

A ideia é que ele não represente apenas o que eu já sei, mas também registre aquilo que estou aprendendo, os problemas que encontrei e as decisões que tomei durante o caminho.

Meu objetivo é construir uma base cada vez mais sólida e, a partir dela, desenvolver aplicações completas e projetos próprios.
